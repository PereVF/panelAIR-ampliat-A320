# panelAIR configuration mock-up

Editable prototype made with plain HTML, CSS and JavaScript.

## Open it

1. Extract the ZIP.
2. Open the folder with VS Code.
3. Double-click `index.html`, or use the VS Code Live Server extension.

## Files

- `index.html`: texts and screen structure.
- `styles.css`: colors, spacing, sizes and responsive design.
- `app.js`: button behaviour for the prototype.

This mock-up does not save settings permanently. Persistence and native actions
should be connected later using the technology used by the real panelAIR app.
